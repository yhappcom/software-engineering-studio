# Software Engineering Studio

Canonical professional knowledge base for reusable software engineering research, executable validation, and cross-project engineering advisory work across yhappcom products.

This repository is **not** a product source repository, snippets collection, or framework cookbook. Its purpose is to build engineering judgment that can be transferred to real products such as MintTap, LogMate, web properties, and future applications.

## Operating model

- `AGENTS.md` — governance, specialist ownership, evidence rules, collaboration boundaries.
- `LEARNING_ROADMAP.md` — beginner-to-research/advisory curriculum.
- `progress/STATUS.md` — coordinator-maintained global state.
- `progress/*_STATUS.md` — specialist state and next-work queues.
- `research/` — canonical reusable engineering research by specialist domain.
- `methods/` — validation, balance-loop, and reusable engineering methods.
- `coordination/` — cross-repository contracts and handoffs.

GitHub is the long-term canonical memory. Chat is temporary working context.
